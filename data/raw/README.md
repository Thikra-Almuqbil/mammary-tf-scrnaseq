# What is in data/raw, and what you have to download yourself

Everything in this folder is real input data. Nothing here was generated by me.

## What is here

| File | What it is | Source |
|---|---|---|
| `sample_info.csv` | The 8 samples, their GEO accessions, and the developmental stage of each mouse. I wrote this file by hand from the GEO series page. | GEO GSE106273 |
| `Mus_musculus_TF.txt` | The AnimalTFDB 4.0 list of mouse transcription factors. 1,611 gene symbols, tab separated, downloaded as the "TF" file (not the TcoF or chromatin-remodeller files). | AnimalTFDB 4.0 |
| `cellranger/GSM28344xx/outs/filtered_feature_bc_matrix/barcodes.tsv.gz` | The cell barcodes for each sample. Real CellRanger output. | GEO GSE106273 |
| `cellranger/GSM28344xx/outs/filtered_feature_bc_matrix/genes.tsv.gz` | The gene annotation for each sample. Real CellRanger output. | GEO GSE106273 |

## What is missing, and why

The one file per sample that is **not** here is `matrix.mtx.gz`, the actual
count matrix. There are 8 of them and they are 12 MB to 31 MB each, about
186 MB in total. GitHub's web upload form rejects any single file over 25 MB,
so I could not put them in the repository. They are public data anyway, so it
would be a duplicate of something GEO already hosts.

I kept the empty folder structure and the two small files so that you can see
exactly where the matrices have to go. Download them and drop them in, and the
scripts run unchanged.

## How to get the count matrices

1. Go to the GEO series page: <https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE106273>
2. At the bottom of the page, under "Supplementary file", click `(custom)` next
   to `GSE106273_RAW.tar` and pick the 8 samples listed in `sample_info.csv`,
   or just download the whole tar.
3. Unpack it. Each sample gives you a `barcodes.tsv.gz`, a `genes.tsv.gz` and a
   `matrix.mtx.gz`.
4. Put each sample's `matrix.mtx.gz` into
   `data/raw/cellranger/<GSM accession>/outs/filtered_feature_bc_matrix/`,
   next to the two files that are already there.

## Two things about this data that cost me time

**These matrices are CellRanger version 2 output.** Version 2 names the gene
annotation file `genes.tsv.gz`. Version 3 renamed it to `features.tsv.gz`, and
`Read10X()` in Seurat looks for the version 3 name. Seurat does have a fallback
for old data, but it only triggers on an *uncompressed* `genes.tsv`, and ours is
gzipped, so the fallback never fires and you get
`Gene name or features file missing. Expecting features.tsv.gz`.
Script `01_import_and_quality_control.R` fixes this by copying `genes.tsv.gz` to
`features.tsv.gz`. It copies rather than renames, so the originals stay intact.
